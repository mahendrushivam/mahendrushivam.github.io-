    AI-assisted, collaborative report builder

    EclecticIQ, 2024 to present, customizable report template builder

    Security analysts spent about an hour assembling each report: pulling charts, graphs, and attack analysis from other modules and pasting them in. I architected a report builder that extends the Froala editor with a plugin system for charts, graphs, attack analysis, and images, and added AI assistance inside the editor.

    The AI side is a multi-agent workflow on Next.js server routes. An orchestrator reads the editor context and routes each request to a specialized agent, each with a schema-validated toolset: Chart and Visualization Widget agents query Elasticsearch and PostgreSQL, and an Attack Analysis agent queries PostgreSQL. Progress streams to the editor over SSE, and nothing is inserted until the analyst approves it.
